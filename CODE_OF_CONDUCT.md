# Code Of Conduct

tmuxes is a technical project for people building and using remote development
tools. Participation here should make that work easier.

## Expected Behavior

- Be direct, specific, and respectful.
- Critique code, designs, tradeoffs, and evidence rather than people.
- Assume public issue threads are shared workspaces.
- Keep reports actionable: include reproduction steps, constraints, and logs
  when they help.
- Remove secrets and private infrastructure details from all public posts.

## Unacceptable Behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Publishing another person's private information.
- Posting credentials, private keys, tokens, or non-public host details.
- Repeatedly derailing technical discussions after maintainers ask to refocus.

## Enforcement

Maintainers may edit, hide, or remove comments; close threads; block accounts;
or restrict participation when necessary to keep the project usable and safe.

Report conduct issues through a private maintainer channel when possible. If a
report involves a security issue, use the process in [SECURITY.md](SECURITY.md).
